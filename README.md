# Hospital-HMIS-Analysis
# 🏥 Hospital HMIS Data Analysis — Power BI & SQL

## 📌 Project Overview

This project focuses on analyzing Hospital Healthcare Management Information System (HMIS) data using **SQL and Microsoft Power BI**.

The objective is to transform hospital data into an interactive dashboard that provides insights across **patients, admissions, hospital operations, billing, drugs, treatment and insurance**.

---

## 🛠️ Tools & Technologies

* **Power BI**
* **SQL / MySQL**
* **DAX**
* **Data Modeling**
* **Data Visualization**
* **Interactive Dashboards**

---

## 📊 Dashboard Pages

### 1. Healthcare Overview

Provides a high-level view of important hospital KPIs and analytical indicators.

### 2. Patient & Admission Analysis

Analyzes:

* Total patients
* Gender distribution
* Age groups
* Admission types
* Department-wise patients
* Doctor-wise visits
* Length of stay
* Treatment costs

### 3. Hospital Operations

Analyzes hospital resources and operations, including:

* Total beds
* Available beds
* Occupied beds
* Bed occupancy
* Wards
* Departments
* Operational activity

### 4. Billing & Payment Analysis

Analyzes:

* Total billing
* Patient payable amount
* Insurance-covered amount
* Payment status
* Treatment costs
* Department-wise treatment costs

### 5. Drug & Treatment Analysis

Analyzes:

* Drug usage
* Drug costs
* Treatment-related information
* Disease and department-level patterns
* Drug cost categories

### 6. Insurance Analysis

Analyzes:

* Insurance coverage
* Coverage limits
* Coverage percentage
* Insurance providers
* Insurance-covered amount
* Patient payable amount
* Coverage by disease
* Coverage by department

## 🗄️ SQL Analysis

SQL was used to perform analytical queries across patient, admission, department, disease and billing data.

Key SQL techniques used:

* `JOIN`
* `GROUP BY`
* `HAVING`
* `COUNT`
* `SUM`
* `AVG`
* `MIN`
* `MAX`
* `CASE`
* Subqueries
* Window functions
* `DENSE_RANK()`

Example analyses include:

* Patient and gender counts
* Emergency admissions
* Treatment costs above ₹50,000
* Average treatment cost
* Department-wise treatment cost
* Disease-wise treatment cost
* Patients above average treatment cost
* Patients with above-average length of stay
* Department ranking based on treatment cost
